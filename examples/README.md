# Examples

Two things live here, meant to be read in order:

1. `context/` — this repository's own `docs/context/`, filled in, as a worked example of
   what onboarding produces (start at `context/README.md`).
2. `task-20260814-onboarding-session5-routing/` — one finished task folder — CONTEXT.md,
   PLAN.md, REVIEW.md — in the shape the current templates define.

Nothing in this folder is copied into an adopter's project — it lives under `examples/`
precisely so nobody inherits it by copying `docs/` or cloning this repo (see
`docs/context/README.md`).

The task folder is reconstructed, not recorded live: the change it documents
(`git show b4e05cb`) was a direct edit, not a session actually run through
`build-context` → `planner` → `reviewer`. Check the three files against that commit to see
how closely the reconstruction holds up.
