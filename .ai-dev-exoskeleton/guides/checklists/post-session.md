# Post-Session Checklist

> Human-optional. Same as the pre-session checklist: a scaffold for building the habit and
> for onboarding a team, not a mandatory ritual.

After EVERY AI coding session, take 2 minutes to answer:

## Outcome
- [ ] Did I achieve the ONE outcome I defined? (yes / partially / no)
- [ ] If partially: what's left? Create a follow-up session scope.

## Quality
- [ ] Did the AI need course corrections? (how many times?)
  - 0 corrections: prompt was well-structured
  - 1-2 corrections: normal
  - 3+ corrections: prompt needed better constraints
- [ ] Did the AI jump ahead of my intent? (started coding when I wanted planning, etc.)
  - If yes: add explicit constraint to prompt next time
- [ ] Were all tests passing at session end?

## Scope
- [ ] Was the scope too big? (ran out of tokens/time)
  - If yes: break it down more next time
- [ ] Was the scope too small? (finished in 3 messages)
  - If yes: can combine with next piece
- [ ] Did scope creep happen? (AI started touching unrelated files)
  - If yes: be more explicit about SCOPE boundaries

## Learnings
- What worked well in this session?
- What would I do differently?
- Any new patterns or anti-patterns to add to the playbook?

## Next Session
- What's the next atomic task?
- Write the prompt now while context is fresh
